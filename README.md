Introduction:
     The Titanic dataset contains passenger details from the ship RMS Titanic, which sank in 1912. It is used to analyze survival patterns 
     using Python and Pandas.

Overview of dataset:
      The dataset includes features like Survived, Pclass, Age, Gender, Fare, and Embarked. It contains numerical and categorical data
      with some missing values. 

Methodology:
      The data was imported and inspected using Pandas functions like head(), info(), and describe(). Missing values were handled, and filtering,
      sorting, and groupby operations were performed for analysis.

Statistical Analysis:
      The survival rate was calculated and compared by gender and passenger class. The analysis shows that females and first-class passengers had
      higher survival rates, and passengers who paid higher fares had better chances of survival.

Conclusion:
      From the analysis, we conclude that gender, passenger class, and fare significantly influenced survival. Proper data cleaning and statistical
      methods helped in identifying meaningful patterns from the dataset.
